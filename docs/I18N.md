# Languages (i18n)

Annie 3D speaks English, Vietnamese, French, Portuguese (Brazil), Spanish, Italian, Russian,
Korean, Japanese and Simplified Chinese. The package `@annie3d/i18n` holds the text for the web
app, the Worker, the desktop shell and the site.

## Rules for every change

1. **No text in code.** Every text a person can read goes through `t('key')`. This covers JSX
   text, `aria-label`, `title`, `placeholder`, `alt`, toasts, dialogs, menus, error messages,
   canvas-drawn text, emails and HTML pages.
   - `i18n.guard.test.ts` fails on text written in the code.
   - The pseudo-locale E2E test fails on text that reaches the screen by any other route.
2. **English first, then all nine languages in the same change.** Add the key to
   `packages/i18n/src/messages/en/<area>.ts`, then to `messages/{vi,fr,pt,es,it,ru,ko,ja,zh}.ts`.
   The compiler rejects a catalog with a missing or extra key. `i18n.test.ts` rejects:
   - a lost placeholder;
   - a missing plural form;
   - text left in English, unless the key is in that file's `sameAsEnglish`.
3. **One sentence is one message.** Never build a sentence from pieces or add an "s" in code.
   - Use placeholders: `'Run {name}'`, `t('run.one', { name })`.
   - Put elements inside a sentence with `rich(t, key, { cost: <span>…</span> })`.
4. **Plurals are objects**: `{ one: '{count} credit', other: '{count} credits' }`, with the count
   passed as `count`. Each language lists the CLDR forms it needs; Russian needs
   one/few/many/other, while Japanese, Korean and Chinese need only `other`.
5. **Numbers and dates are formatted by the language.** Pass a number as a number: `t` formats
   it (1,234 / 1.234 / 1 234). `t.number()` and `t.date()` cover the rest. Never call
   `toLocaleString('en')` for display.
6. **People's own content is not translated**: board titles, labels they typed, prompts, file
   names, account names and emails. Mark the element that shows such content with
   `translate="no"` (standard HTML: browser translators and the pseudo-locale test skip it).
   Defaults the product writes (a starter's node labels, a sample headline) are translated
   when they are created.
7. **The language picker lists names, never flags.** A flag stands for a country, not a
   language, and flags are politically sensitive. Each language is written in itself: Tiếng
   Việt, Français, 日本語. `i18n.test.ts` checks the list and rejects flag emoji in any catalog.
8. **Names that stay the same everywhere**: Annie, Annie 3D, GLB, MP4, PNG, ZIP, TikTok, Google
   Merchant, Google Swirl, the plan names Creator and Studio, keyboard keys (⌘, ⌥, ⇧). Mark a code line that must keep literal text
   (a brand, a technical acronym such as LCP in the developer panel) with `// i18n-ignore`.

## Keys

- Keys are flat and dotted: `<area>.<place>.<purpose>`, for example `topbar.runAll`,
  `dialog.export.title` or `api.boardNotFound`.
- Each English file owns fixed prefixes. The test enforces them, so two files cannot define the
  same key.

| File | Prefixes |
| --- | --- |
| `common.ts` | `common.` |
| `contracts.ts` | `node.` `engine.` `category.` `port.` `portType.` `look.` `motion.` `glbPreset.` `simEnv.` `starter.` `setting.` |
| `chrome.ts` | `app.` `topbar.` `toolbar.` `palette.` `menu.` `agent.` `dialog.` `perf.` `signin.` `update.` `lang.` |
| `canvas.ts` | `canvas.` `board.` `run.` `reel.` `file.` |
| `editor.ts` | `editor.` |
| `sim.ts` | `sim.` |
| `api.ts` | `api.` |
| `desktop.ts` | `desktop.` |
| `site.ts` | `site.` `share.` |

## Where the language comes from

1. `?lang=xx` in the URL. `?lang=en-XA` is the test pseudo-locale: accented text in ⟦ ⟧.
2. The person's pick, saved in `localStorage` (`annie3d.lang`) and in the cookie `annie3d_lang`.
   The Worker reads the cookie for its messages and pages; the site and the app share it.
3. The browser's languages (`navigator.languages`, or `Accept-Language` on the server), matched
   by primary subtag.
4. English.

## Runtime

- **Web app** (`apps/web/src/client/i18n.tsx`):
  - `useT()` in components and `t` outside React.
  - `setLocale()` re-renders everything with no reload.
  - English is built in. Each other language is one lazily loaded chunk, fetched before the
    first paint only when it is the chosen language.
- **Worker, desktop shell, site**: `translator(locale)` from `@annie3d/i18n/all` holds every
  language at once.

## Tests that keep it that way

| Test | Catches |
| --- | --- |
| `apps/web/src/client/i18n.guard.test.ts` (uses `scripts/i18n-scan.mjs`) | text written in JSX, text attributes or toasts |
| `packages/i18n/src/i18n.test.ts` | missing or extra keys, lost placeholders, missing plural forms, English left in a translation, contract names without a key, flags |
| `tests/e2e/i18n.spec.ts`, pseudo-locale | any word on screen that did not go through `t()`: menus, dialogs, editor, simulator, server errors |
| `tests/e2e/i18n.spec.ts`, fit | in every language, at 1440 px and 390 px: bars that overflow, buttons that cut their text |
| `apps/web/src/worker/lib/i18n.test.ts` | the Worker's language choice (cookie, then Accept-Language) and translated errors and pages |
| `tests/desktop/desktop.spec.ts` | the shell's menus follow the picked language, and the choice survives a restart |

## Fonts

- Instrument Sans covers Latin only.
- Vietnamese and Russian use Inter, which is self-hosted and downloaded only in those languages.
- Chinese, Japanese and Korean use the system's UI font, selected with `:lang()` in `app.css`.
